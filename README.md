# KNS Real Estate — React website

A responsive luxury real-estate landing page built with React, Vite, Framer Motion and Lucide icons.

## Requirements
- Node.js (LTS version recommended)
- npm (included with Node.js)

## Run locally

1. Extract this ZIP.
2. Open the extracted `KNS-Real-Estate` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address printed in the terminal (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Before publishing
- Replace illustrative image URLs with approved KNS project photos.
- Confirm the official project address, phone number, email, approvals, plot dimensions, pricing and amenities.
- The enquiry form is currently a front-end demo. Connect it to an email service or backend before publishing.
- The project statistics and facilities are editable in `src/App.jsx`; confirm all details before public use.

## Main files
- `src/App.jsx` — page sections and content
- `src/styles.css` — responsive styling
- `index.html` — page title, fonts and metadata
